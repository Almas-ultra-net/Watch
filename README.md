# ⌚ الماس — سازنده و سفارشی‌ساز ساعت سه‌بعدی

یک وب‌اپلیکیشن تعاملی فارسی (RTL) برای طراحی، سفارشی‌سازی و امتحان‌کردن ساعت مچی سه‌بعدی — با رندر **PBR**، مواد فلزی/چرمی/پارچه‌ای، عقربه‌های هم‌زمان با زمان واقعی، حالت تاریک/روشن و **واقعیت افزوده (WebXR AR)** برای امتحان ساعت روی مچ دست.

> 🌐 نسخهٔ زنده: **https://almas-ultra-net.github.io/Watch/**

---

## ✨ ویژگی‌ها

### مدل سه‌بعدی و رندر
- ساعت کامل سه‌بعدی که به‌صورت **رویه‌ای (Procedural)** با Three.js ساخته می‌شود — بدون هیچ فایل مدل خارجی، سبک و سریع
- بدنه با پروفیل گرد (Lathe)، بزل، شیشهٔ یاقوتی با انکسار واقعی (Transmission)، تاج دندانه‌دار، شاخک‌ها، رهوت و نشانگرهای فلزی
- مواد **PBR**: طلا، نقره، مس، رزگلد و استیل با بازتاب محیطی (RoomEnvironment + PMREM)
- بافت‌های رویه‌ای Canvas: صفحهٔ سان‌بورست با ریل‌راه دقیقه، چرم دانه‌دار با دوخت، پارچهٔ ناتوی جناغی
- سایهٔ نرم (PCF Soft Shadows) و تون‌مپینگ ACES Filmic

### تعامل
- 🖐️ کشیدن و چرخاندن ساعت در فضای سه‌بعدی (OrbitControls با Damping)
- 🔍 بزرگ‌نمایی با اسکرول ماوس یا دو انگشت
- 🎯 دکمهٔ **بازنشانی دوربین**
- ✨ نزدیک‌کردن ماوس به اجزای پیچیده (عقربه‌ها، بزل، نشانگرها، تاج، بند) → **درخشش ملایم و راهنمای شناور فارسی**

### ساعت زنده
- عقربه‌های ساعت/دقیقه/ثانیه بر اساس **زمان محلی واقعی** با حرکت پیوسته و صاف (Sweep)
- سه سبک عقربه: **مدرن**، **کلاسیک (بورِگه)** و **مینیمال** + رنگ عقربه (همرنگ بدنه/فولادی/طلایی/مشکی)
- ساعت دیجیتال و تاریخ شمسی در هدر با ارقام فارسی

### سفارشی‌سازی بند
- نوع بند: **چرم** (با سگک)، **متالیک** (حلقه‌های فلزی) و **فلکسیبل/ناتو** (پارچه‌ای کشسان)
- رنگ‌بندی مخصوص هر نوع، **طول** (کوتاه/استاندارد/بلند) و **شکل** (منحنی دور مچ / صاف برای نمایش)

### واقعیت افزوده (AR)
- دکمهٔ **«امتحان روی مچ دست»** با WebXR (`immersive-ar` + `hit-test` + `dom-overlay`)
- قرار دادن ساعت با مقیاس واقعی (قطر ۴۲ میلی‌متر) روی هر سطح/مچ + چرخش و تغییر اندازه در AR
- اگر WebXR در دسترس نباشد: پیام راهنما + **پیش‌نمایش جایگزین با دوربین** (getUserMedia)

### رابط کاربری
- تمام‌فارسی و **RTL** با فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (Vazirmatn)
- پانل تنظیمات سایدباری (در موبایل: Bottom-Sheet) برای همهٔ گزینه‌ها با پیش‌نمایش زنده
- حالت **تیره/روشن**، واکنش‌گرا، بهینه برای دسکتاپ و موبایل (نمایشگر FPS برای پایش رندر ۶۰ فریمی)

## 🚀 نصب و اجرای محلی

پیش‌نیاز: **Node.js 18+**

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه (http://localhost:5173)
npm run dev

# اجرای تست‌ها
npm test

# ساخت نسخهٔ نهایی در پوشهٔ dist
npm run build

# پیش‌نمایش نسخهٔ ساخته‌شده
npm run preview
```

> حالت توسعه به‌صورت خودکار روی شبکهٔ محلی هم گوش می‌دهد (`--host`) و میزبان‌های تونل را می‌پذیرد.

## 🎨 افزودن گزینهٔ جدید

همهٔ گزینه‌ها در `src/config/options.js` تعریف شده‌اند؛ کافی است یک آیتم به آرایهٔ مربوطه اضافه کنید (مثلاً `CASE_MATERIALS`) — رابط کاربری و صحنهٔ سه‌بعدی به‌صورت خودکار آن را پیدا می‌کنند.

## 🥽 نیازمندی‌های حالت AR

حالت «امتحان روی مچ دست» به **WebXR AR** نیاز دارد:

- گوشی اندروید با **Chrome یا Edge** (نسخهٔ ۸۱ به بعد)
- باز شدن سایت روی **HTTPS** (مثل GitHub Pages)
- دسترسی به دوربین

روی دسکتاپ و مرورگرهای بدون WebXR-AR، پیام راهنما نمایش داده می‌شود و می‌توانید از **پیش‌نمایش دوربین** به‌عنوان جایگزین استفاده کنید.

## ⚙️ استقرار خودکار (GitHub Actions)

`.github/workflows/deploy.yml` پس از هر push به `main` (یا اجرای دستی):

1. **تست:** `npm ci` → `npm test` (۱۹ تست: زمان، گزینه‌ها، صحت هندسهٔ مدل)
2. **ساخت:** `npm run build` با `base` خودکار `/Watch/`
3. **انتشار:** خروجی `dist/` به شاخهٔ **`gh-pages`** منتقل می‌شود (`peaceiris/action-gh-pages`)
4. **فعال‌سازی Pages:** سرویس GitHub Pages از شاخهٔ `gh-pages` تنظیم می‌شود → آخرین نسخه به‌صورت خودکار زنده است
